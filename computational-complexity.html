A Study in Computational Complexity

Computational complexity describes how the work and memory an algorithm needs grow as its input gets larger. Explore both using square matrix multiplication.

Algorithm

× =

Row 1 × column 1

1 × 5 + 2 × 7 = 19

Multiply the matching entries from row 1 of A and column 1 of B, then add the products. Put the sum in row 1, column 1 of the result. Repeat for each row and column pair.

Implementation in Python

matrix_multiplication.py
def multiply_square_matrices(a, b):
    n = len(a)
    result = [[0] * n for _ in range(n)]
    column = [0] * n

    for j in range(n):
        for k in range(n):
            column[k] = b[k][j]

        for i in range(n):
            total = 0
            for k in range(n):
                total += a[i][k] * column[k]
            result[i][j] = total

    return result

How it works

A square matrix has the same number of rows and columns. Both inputs, a and b, are square and have the same dimensions.

n · Input-size parameter
The number of rows or columns in either input. Each input contains n² entries.
column · Reusable buffer
A temporary list that holds one column of b. All rows of a use that copy before it is overwritten with the next column.
i and j · Output position
They select a row of a and a column of b for one result cell.
k and total · Inner loop
k visits each pair of entries. total adds up their products to compute the dot product for one result cell.

How the steps are counted

Loop control. Count one iterator setup and n + 1 advances, including the final attempt that ends the loop. A successful advance includes binding the loop variable. The column loop starts once, the copy and row loops start n times each, and the dot-product loop starts n² times.

Allocation. The result costs n² + 3n + 4 steps. Count one to create the outer list, n + 2 for the comprehension's loop, n + 2 per row to build it, fill it with zeros, and append it, and one to assign result. The buffer costs n + 2 steps to build, fill, and assign.

Indexing. Copying an entry from b reads its row and cell. Each multiply-add reads two entries through a[i][k] and one through column[k]. Storing a result reads its row once. Each buffer or result write costs one step.

Big O settings and explanation

Big O asks whether some constant C gives T(n) ≤ C × n³ for every n ≥ n₀. The ratio T(n) / n³ = 7 + 11/n + 9/n² + 11/n³ decreases toward 7. Any C > 7 therefore gives an eventual bound.
