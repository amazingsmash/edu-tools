# Edu Tools

Repositorio de herramientas educativas interactivas para la asignatura **Habilidades Profesionales para Ingenieros**.

Este material ha sido creado por el **profesor doctor Jos&eacute; Miguel Santana N&uacute;&ntilde;ez**, de la **Universidad de Las Palmas de Gran Canaria**, en el **Departamento de Ingenier&iacute;a Inform&aacute;tica**.

## Finalidad

El objetivo de este repositorio es reunir recursos web sencillos, autocontenidos e interactivos que sirvan como apoyo a la docencia, la explicacion de conceptos y el trabajo autonomo del alumnado en la asignatura.

Las herramientas estan pensadas para facilitar la comprension visual de ideas, procesos y modelos que pueden aparecer en actividades formativas vinculadas al desarrollo de competencias profesionales en ingenieria.

## Contenido

El repositorio incluye actualmente:

- `index.html`: portal principal de acceso a las herramientas.
- `spain-tax-visualizer.html`: visualizador interactivo de impuestos en Espana.
- `probability_distribution_function.html`: simulacion interactiva de distribuciones de probabilidad y ley de los grandes numeros.
- `hpi-theory-hub.html`: hub de teoria, videos, vocabulario y recursos organizados por secciones.
- `charts_showcase.html`: galeria o muestra de visualizaciones y graficos.
- `ui_elements_catalog.html`: catalogo de elementos de interfaz reutilizables.
- `temp_script.js`: script auxiliar utilizado durante el desarrollo.

## Uso

No es necesario instalar dependencias para usar las herramientas principales. Basta con abrir `index.html` en un navegador moderno y acceder desde ahi a cada recurso.

Tambien se puede abrir directamente cualquiera de los ficheros `.html` individuales.

## Contexto docente

Este repositorio se enmarca en la asignatura **Habilidades Profesionales para Ingenieros**, orientada al desarrollo de competencias transversales y profesionales necesarias para el ejercicio de la ingenieria.

Entre los posibles usos docentes de estos materiales se incluyen:

- Apoyar explicaciones en clase mediante visualizaciones interactivas.
- Proponer actividades practicas de exploracion guiada.
- Facilitar el aprendizaje autonomo del alumnado.
- Experimentar con interfaces educativas y recursos digitales.
- Servir como base para futuras ampliaciones o prototipos docentes.

## Estructura tecnica

El proyecto esta construido principalmente con HTML, CSS y JavaScript en ficheros autocontenidos. Esta estructura permite que los recursos sean faciles de distribuir, abrir y modificar sin depender de un entorno de ejecucion complejo.

## Estado del proyecto

Este repositorio puede evolucionar con nuevas herramientas, mejoras de interfaz, materiales de apoyo y recursos adicionales para la asignatura.
